# Manual Script Archive

This folder contains ad-hoc/manual Python helper scripts that were previously kept in the repository root.

They were moved here to keep the project root clean while preserving historical tooling used during debugging and validation.

## Archived Scripts

- `benchmark.py` - Basic latency benchmark and health checks.
- `cache_test.py` - Cache stats check before/after selected business endpoints.
- `concurrent_test.py` - Simple concurrent request test with generated JWT.
- `generate_token.py` - Prints a short-lived development JWT.
- `measure_endpoints.py` - Side-by-side latency check for localhost vs 127.0.0.1.
- `request_script.py` - Repeated sequential requests to selected business endpoints.
- `task_execution.py` - Request timing check against business and gateway endpoints.
- `task_request.py` - Cache stats + endpoint timing smoke check.
- `test_db.py` - Direct database connectivity and review table inspection helper.
- `test_script.py` - Basic endpoint timing and cache stats printout.

## Notes

- These scripts are not part of the main automated test pipeline.
- Primary maintained test entry points remain under `scripts/` (for example `scripts/test-all.ps1`, `scripts/cache_load_test.py`, `scripts/traffic_live_monitor.py`).
- Outputs generated by these archived scripts should remain under `test-results/` for consistency.
